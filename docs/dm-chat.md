# Gemini DM 일반 대화

## 사용자 동작

| 보내는 내용 | 처리 |
| --- | --- |
| 일반 텍스트 | Gemini 일반 대화. 팩트체크 접수 안내를 보내지 않음 |
| Instagram 링크 또는 릴스·게시물·이미지 첨부 | 기존 콘텐츠 확보·분석. 접수 안내 후 결과 전송 |
| `연결`, `로그인`, `대시보드` | 기존 일회용 계정 연결 링크. 일반 대화보다 우선 |
| `대화 초기화`, `/초기화`, `새 대화` | 최근 대화 맥락을 지우고 새로 시작 |

일반 텍스트에서 사실 주장 추출을 강제하지 않는다. 질문·설명·아이디어·글쓰기 같은 요청은 자연어로 답한다. 일반 대화에 웹 검색을 붙이지 않았으므로 최신 정보·실제 출처 확인을 했다고 답하지 않도록 지시한다.

콘텐츠 공유 결과도 최근 대화 맥락에 넣어 “그 결과를 짧게 설명해줘” 같은 후속 질문에 활용한다. 이미지·영상 파일은 이 맥락에 넣지 않고 기존 미디어 처리 종료 시 정리한다. 음식·전시·공모전별 전용 정리 프롬프트는 팀원이 담당하며, 이번 변경은 기존 콘텐츠 처리 프롬프트를 유지한다.

## 구현과 팀원 연결

- `api/instagram.mjs` → `dmAssistantFromEnv` → `createDmAssistant`.
- `server.mjs`의 새 `respondToMessage(message, { senderId })` 경로가 텍스트와 콘텐츠를 분기한다. 기존 `factCheck` 주입도 그대로 지원한다.
- 일반 대화 응답을 Supabase 팩트체크 이력으로 저장하지 않는다. 발신자 추적·계정 연결·프로필 조회 보완은 기존 팀원 코드를 유지한다.
- `GEMINI_API_KEY`와 `GEMINI_MODEL`을 그대로 사용한다. 새 키나 서비스가 필요하지 않다. Gemini가 없는 Continuum-only 구성은 기존 콘텐츠 처리로 동작한다.
- 메시지는 UTF-8 900바이트 단위로 나누고 이모지의 surrogate pair를 분리하지 않는다. 모델 오류는 일반 대화용 재시도 안내를 보낸다.

## 최근 대화 맥락

- 사용자별 최근 12개 메시지, 즉 대략 6회 왕복을 사용한다. 마지막 갱신 후 30분을 넘으면 모델에 전달하지 않는다.
- 비공개 Blob의 `dm/chat/<sender 해시>.json`에 AES-GCM 암호화 저장한다. 원문 발신자 ID나 대화 본문을 파일명·로그에 남기지 않는다.
- `대화 초기화` 요청에서는 해당 사용자의 맥락 파일을 실제 삭제한다. 만료된 맥락도 다음 메시지 수신 시 삭제·교체한다.
- 30분은 모델이 기억하는 기간이다. 비활성 사용자의 파일을 30분 정각에 삭제하는 주기 작업은 없다. 장기 대화 기록 DB나 대시보드의 대화 이력 구현과는 별개다.
- 저장소 장애 때는 맥락 없이 답장한다. 초기화 실패를 성공으로 안내하지 않는다.
- 여러 서버 인스턴스에 같은 사용자의 메시지가 동시에 들어오면 마지막 저장이 앞선 맥락을 덮을 수 있다. 지속적인 동시 사용으로 확대할 때 사용자별 큐가 필요하다.

## 원본 주소가 없는 공유의 보완

- `ig_reel`/`reel` 첨부 URL이 Meta CDN의 **실제 MP4**이면 원본 Instagram 페이지 주소 없이 바로 Gemini 영상 경로에 전달한다. 실제 MP4 시그니처·공개 주소·크기 제한을 확인하고, 처리가 끝나면 원본 버퍼를 비운다. 커버 이미지를 전체 영상으로 처리하지 않는다.
- 하나의 공유가 `share`와 `ig_post` 두 첨부로 표현돼도, 동일 메시지에서 원본 링크 하나를 확보하면 여러 게시물로 오인하지 않는다.
- 카드뉴스에서 CDN 이미지 한 장만 오고 원본 URL도 없으면 전체 장수를 복원했다고 말할 수 없다. 해당 경우의 링크 요청은 아직 남아 있다.
- 기존 수신 메시지 ID로 `id`, `shares{link}`, `shares{link,name,description}`를 다시 조회했지만 Facebook Graph는 HTTP500/code1, 현재 토큰을 Instagram Graph 호스트에 보내면 HTTP401/code190이었다. 이번 실험은 새 메시지 상세나 전체 카드뉴스 URL을 확보하지 못했다. 이 결과를 토큰 만료로 단정하지 않는다.
- 모든 공유를 추가 입력 없이 처리하려면 별도 원본 확보 수단이 더 필요하다. Instagram 로그인 세션을 사용하는 수집 워커는 추가 검증 대상이며, 이번 변경에서 로그인 쿠키를 추출하거나 별도 워커를 운영하지 않았다.

## 검증

- 일반 대화/콘텐츠/계정 연결 분기, 오류 응답, 사용자 분리·암호화·맥락 제한·만료·초기화, 이모지 분할을 테스트했다.
- 실제 Gemini와 비공개 클라우드 맥락으로 2회 대화를 수행하고, 첫 메시지의 테스트 코드를 두 번째 답변에서 기억하는 것과 초기화 후 맥락이 없는 것을 확인했다. 이 검증은 Instagram DM을 발송하지 않았다.
- 전체 Node 테스트 77개, Python 테스트 13개가 통과했다. 배포 후 실제 Instagram DM 답장은 별도 확인이 필요하다.
